# Immunity Core documentation

Immunity Core is the open-source detection core of Artificial Immunity, for one Mac. This page lists the documents in the repository and says which to open for which question. The repository's first page is the [README](../README.md).

| You want to | Open |
|---|---|
| Build the core and run a first check | [README, first run](../README.md#first-run) |
| Understand the parts, findings, answers and verdicts | [How it works](how-it-works.md) |
| Look up a command, a flag, a file the core keeps, or how to update and remove it | [Reference](reference.md) |
| See where the vulnerability data and the rules come from, and what the core downloads | [Threats](threats.md) |
| Install the collector that lets rules judge every program start | [The collector](event-level.md) |
| Add a Sigma rule of the core's own | [Writing a rule](rules.md) |
| See how many of Atomic Red Team's macOS tests the core notices | [Attack simulations](atomic.md) |
| Run the core as a login job | [Background service](core-service.md) |
| Read the types a program that runs the core reads and writes | [The contract](../contract/README.md) |
| Teach your coding agent to look into a finding read-only | [Agent skill](../skill/immunity-core/SKILL.md) |
| See what changed | [Changelog](../CHANGELOG.md) |
| Change the code | [CONTRIBUTING.md](../CONTRIBUTING.md) and [AGENTS.md](../AGENTS.md) |
| Report a vulnerability | [SECURITY.md](../SECURITY.md) |

The same pages are on the website, with a Markdown copy of each for AI agents: [immunity.bot/docs](https://immunity.bot/docs/).
